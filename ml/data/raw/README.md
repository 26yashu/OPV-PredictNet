# Raw Experimental Datasets

This directory holds raw, unedited experimental datasets extracted from published literature repositories and experimental OPV databases.

## Standards for Inclusion:
1. Every record must specify the donor material (SMILES or IUPAC name) and acceptor material (SMILES or IUPAC name).
2. Reported figures of merit must derive from standardized measurement protocols (AM1.5G, 100 mW/cm² irradiance, 25°C).
3. Process parameters (solvent, additive, annealing temperature) should be preserved where reported.

Note: Raw datasets are excluded from Git commits via `.gitignore` to prevent repository bloat and license conflicts.
